# Community model links

Author: Colin Rooney · © 2026 Rooney Industries LLC

This voluntary catalog is **empty**. No community weights are included or hosted here.

To propose an external model link, open a pull request editing this page. Include:

- Model name, author attribution and direct weights URL; source repository and immutable source revision.
- Required runtime and exact version, dependencies and configuration.
- Weight license and any separate source/backbone licenses; permission to distribute at the linked location.
- Exact weight filename and SHA-256 hash.
- Input shape, encoding, units and preprocessing; output names, shapes, units and sign conventions.
- Camera calibration and mounting assumptions, including phone/camera variant.
- Tested conditions, supporting evidence and known limits; distinguish replay, bench and physical-drive results.

A link is a contribution for review, not a compatibility claim or endorsement. Contributors retain responsibility for their external hosting and licensing. This page does not create an upload service, download automation or a new supported controller path. Use the [public ROS repository](https://github.com/12mv2/robo-bump-truck-ros#build-and-test) for current interface setup/build/demo/replay guidance; physical use still needs the [build checkpoints](../docs/build-checkpoints.md).

The project's own historical OVAL4 record remains on [the model page](README.md).
